# Temporal Speech Markers of Dementia in Clinical Interviews

Code accompanying the paper:

> **Temporal Speech Markers of Dementia in Clinical Interviews: A Lossless, Clinician-Validated Pipeline and Pilot Study**
> Submitted to the ICASSP 2027 Satellite Workshop on Speech Biomarkers for Neurodegenerative Diseases (SBiND).

## Status

🚧 **The code will be released here after the review process.**

This repository is a placeholder. Watch or star it to be notified when the release is available.

## What will be released

- **Recording tool:** a browser-based application that captures the participant's speech losslessly on a tablet (48 kHz, 24-bit) in parallel with the clinician's channel over a local WebRTC link.
- **Alignment:** envelope cross-correlation that synchronizes the lossless participant track with the received stereo recording.
- **Annotation tool:** a waveform view for clinicians to label intervals (e.g., long pauses, hesitations).
- **Analysis pipeline:** speech activity detection, cross-talk removal, pause and turn segmentation, syllable-nuclei detection, and the pre-specified temporal measures (speech rate, pause time per word, pause-time ratio, articulation rate, response latency, pauses per word).

## Data availability

The recordings contain identifiable speech from clinical interviews and **cannot be shared**. Only code, configuration files, and documentation will be released.
